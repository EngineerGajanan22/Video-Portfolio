# 🎥 Gajanan Gangakhedkar — Video Portfolio

Modern, interactive full-stack developer portfolio built with **React 19**, **Vite**, **Tailwind CSS v4**, **Framer Motion**, and **AOS**.

---

## 🚀 Features

- **Hero Video Showcase**: Dynamic autoplay background reel with ambient audio controls (Mute / Unmute).
- **Interactive Preloader**: Liquid fill motion animation that transitions smoothly into the portfolio.
- **Collaborations & Inquiries Section**:
  - Live visitor inquiries recorded with **User Name**, **Email Address**, **Message / Inquiry**, and **Submission Date/Time**.
  - Direct **FormSubmit** AJAX integration delivering submissions straight to inbox.
  - Persistent storage powered by `localStorage`.
- **Career Milestones & Experience**: Detailed timeline of professional roles at Cyber Rafting, Amazon, and Codec Technologies.
- **Featured Projects**: Production-ready full-stack applications (AI Resume Coach, Shopify Storefront, Product & Item Hub).
- **Technical Skills Matrix**: Comprehensive categorization of languages, frameworks, backend architecture, and DevOps tools.
- **Responsive Navigation**: Smooth section navigation and mobile drawer menu.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS v4
- **Animations**: Framer Motion, AOS (Animate On Scroll)
- **Email Delivery**: FormSubmit.co AJAX API
- **Deployment Ready**: Optimized production build via Vite

---

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/EngineerGajanan22/Video-Portfolio.git

# Navigate into the project directory
cd Video-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173/` in your browser.
